// FEATURES

为摸鱼而生的核心功能

每一个细节都为了「不被发现」而设计

本地导入

支持 .txt，自动识别 UTF-8 / GBK / UTF-16 编码，读取后全量保存在浏览器本地，不上传任何服务器。

自由摆放

位置、宽高精确可调，也能直接拖动面板、拖拽右下角缩放。背景色、透明度、毛玻璃、圆角任你定制。

双阅读模式

翻页模式一屏一页，底栏显示页码；滚动模式整本连续阅读，显示已读字数。一键切换，进度自动保存。

AI 总结

右侧分栏面板，选择「本页 / 最近 3 页 / 整本」范围，流式输出总结，支持 Markdown、历史回看与跳回原文。

一键隐身

网页内快捷键 Alt+Q 瞬间收起，再按一次恢复。另有浏览器级快捷键 Ctrl+Shift+F，领导走过也不慌。

隐私优先

配置存 sync，小说与进度存 local，均只在本机。AI 请求由 Service Worker 直发你的 Base URL，不经第三方中转。

// INSTALL

四步完成安装

零构建原生扩展，不需要 npm install

01

下载压缩包

从下方下载区获取 FishOne 最新版 zip 压缩包并解压到本地。

02

打开扩展页

打开 Edge，地址栏输入 edge://extensions 回车。

03

开启开发者模式

打开左下角「开发人员模式」开关。

04

加载解压缩扩展

点击「加载解压缩的扩展」，选择解压后的文件夹（含 manifest.json）。

// USAGE

上手即用

导入小说即可开始摸鱼

1

导入小说

点击工具栏 FishOne 图标 → 「导入小说」，或在设置页 / 阅读器空状态导入 .txt 文件。

2

自由阅读

滚轮向下 / ↓ / PageDown 下一页，向上 / ↑ / PageUp 上一页。点底栏切换翻页 / 滚动模式。

3

一键隐身

按 Alt+Q（或自定义快捷键）隐藏阅读器，再按一次恢复。进度自动保存。

4

AI 总结

点击面板右上角 AI，选择总结范围（本页 / 最近 3 页 / 整本），点「开始总结」即可。
