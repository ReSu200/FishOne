# 摸鱼一号 FishOne

上班摸鱼看小说的 Edge 浏览器扩展。小说以一个可自由摆放的悬浮面板盖在任意网页上，滚轮或方向键翻页，一个快捷键即可瞬间收起，还能调用 AI 快速总结当前章节。

## 功能

- **导入本地小说**：支持 `.txt`，自动识别 UTF-8 / GBK / UTF-16 编码，读取后全量保存在浏览器本地
- **自定义显示区域**：位置、宽度、高度都可在设置页精确填写，也能直接拖动面板、拖拽右下角缩放
- **自定义外观**：背景色、背景不透明度、毛玻璃模糊、圆角、文字颜色、字号、行高、边框
- **翻页**：鼠标滚轮、方向键 ↑↓←→、PageUp / PageDown；阅读进度自动保存并在下次打开网页时恢复
- **一键隐身**：网页内快捷键（默认 `Alt+Q`，可在设置页按下组合键重新录制）；另有浏览器级快捷键 `Ctrl+Shift+F`
- **AI 总结**：面板内可直接编辑要总结的文本，使用 OpenAI 兼容协议流式输出；API Key、Base URL、模型、温度、最大 Tokens、系统提示词均可配置
- **Token 统计**：设置页「Token 统计」页查看 AI 总结的提示 / 补全 / 合计 Tokens 与调用次数，支持一键清空；服务未返回用量时按字符估算并标注
- **中英文界面**：设置页可切换「跟随浏览器 / 中文 / English」，阅读器与弹窗同步刷新
- **黑夜 / 白天两套配色**：设置页顶部一键切换，界面与弹窗同步，选择会记住
- **弹窗面板**：工具栏图标打开，快速查看进度、导入小说、显示 / 隐藏、翻页
- **赞助页**：设置页「赞助」页展示插件简介与支付宝 / 微信收款码，图片从 `assets/sponsor/` 读取，页面内不可修改

## 安装

1. 打开 Edge，地址栏输入 `edge://extensions`
2. 打开左下角「开发人员模式」
3. 点击「加载解压缩的扩展」，选择本项目根目录（含 `manifest.json` 的目录）
4. 首次使用建议在扩展详情里点击「扩展选项」完成配置

> 本项目为零构建的原生 Manifest V3 扩展，不需要 npm install 或打包步骤。

## 使用

1. 点击工具栏中的 FishOne 图标 → 「导入小说」，或在设置页 / 阅读器空状态中导入 `.txt`
2. 导入后阅读器会自动出现在当前网页上；拖动顶部栏可移动，拖动右下角可缩放
3. 滚轮向下 / `↓` / `PageDown` 下一页，向上 / `↑` / `PageUp` 上一页
4. 按 `Alt+Q`（或你自定义的快捷键）隐藏，再按一次恢复
5. 点击面板右上角 `AI`，编辑待总结的文字后「开始总结」

## 设置说明

| 设置项 | 说明 |
| --- | --- |
| 显示与尺寸 | 左侧 / 顶部距离、宽度、高度，单位 px |
| 外观 | 背景色与不透明度越低越不容易被发现，可配合毛玻璃模糊 |
| AI 模型 | 任意 OpenAI 兼容服务。DeepSeek 示例：Base URL `https://api.deepseek.com`，模型 `deepseek-chat` |
| 快捷键 | 点击输入框后按下组合键即可录制，需含 `Ctrl` / `Alt`，或使用 `F1`–`F12` |
| 通用 | 界面语言、小说导入与清除 |
| Token 统计 | 查看 AI 总结的 Tokens 消耗与调用次数，可清空 |
| 赞助 | 插件简介与收款码展示 |

赞助页的收款码只从扩展目录读取，页面内不提供任何上传、替换或删除入口：

| 槽位 | 依次尝试的路径 |
| --- | --- |
| 支付宝 | `assets/sponsor/alipay.png` → `alipay.jpg` → `alipay.jpeg` |
| 微信 | `assets/sponsor/wechat.png` → `wechat.jpg` → `wechat.jpeg` |

放好图片后重新加载扩展即可显示；任一槽位没有匹配的图片时显示「FishOne 未放置收款码」。扩展更新时这些图片随包替换，使用者无法修改。

设置页顶栏右侧还提供「白天 / 黑夜」主题切换，切换后立即生效并自动保存。

浏览器级快捷键（`Ctrl+Shift+F`）如需修改，请到 `edge://extensions/shortcuts`。

## 隐私

所有配置保存在 `chrome.storage.sync`，小说正文、阅读进度与 Token 统计保存在 `chrome.storage.local`，均只存在本机浏览器中。AI 请求由扩展的 Service Worker 直接发往你填写的 Base URL，不经任何第三方中转。

## 目录结构

```
manifest.json          扩展清单（Manifest V3）
background.js          Service Worker：AI 请求转发、浏览器级快捷键
lib/i18n.js            运行时中英文文案
lib/storage.js         设置、小说、进度的存储封装
lib/novel.js           txt 编码识别与文本规范化
lib/ai.js              OpenAI 兼容协议封装（流式）
content/content.js     网页内悬浮阅读器
content/content.css    阅读器样式
popup/                 工具栏弹窗
options/               设置页
_locales/              扩展名称与描述的国际化
icons/                 图标
```
